THESIS
An intimate watercolor flower studio inside Letters: airy, tactile, romantic, and unmistakably usable on an iPhone.

OWN-WORLD
The bouquet area uses the approved blush paper palette, Cormorant Garamond display type, warm system-sans controls, restrained monoline icons, and rounded petal-soft geometry. It is visually related to Letters but has its own Home / Create / Bouquets shell.

STORY
The shell welcomes the sender into Bloom, then keeps the bouquet continuously present inside one immersive studio. A docked tray exposes the essential tools; expanding it reveals the full library without navigating away or moving the bottom tab bar. The rose, tulip, and daisy pilot family establishes the production botanical language before the remaining catalog and canvas manipulation are introduced.

FIRST VIEWPORT
At iPhone width, the create route is a viewport-locked stack: safe-area header, flexible bouquet canvas, overlapping docked tray, and persistent Home / Create / Bouquets navigation. The expanded tray dims the canvas only and stops above the visible tab bar. At desktop width, keep the same persistent studio while allowing the tray and selection controls more room.

FORM
Direction is pinned by the user's bouquet.png reference and October 1 architecture correction. Use gentle asymmetry, paper-like warmth, soft radii, quiet shadows, and clean outlined symbols. The bouquet leads, controls float lightly, and tool density belongs in the tray; avoid routed wizard pages, document scrolling inside the builder, sharp corners, generic glass panels, loud gradients, and ornamental clutter.
